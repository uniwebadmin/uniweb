# Owner Communication

## Language

- Talk to the owner in **simple everyday Hindi / Urdu** (Delhi style).
- Short lines. No heavy tech jargon.
- Website / product UI text stays **English**.

## Explanation-first mode for new proposals/research

When presenting any new research finding, priority list, or proposal that the owner has **not** already approved:

- **Do NOT start implementation.** Wait until the owner explicitly says "start karo".
- The owner may ask questions one at a time. For each question, explain in very simple, non-technical language:
  - **Kya hai** — what it is
  - **Kya fayda hai** — what the benefit is
  - **Na kare to kya ho sakta hai** — what the risk is if not done
- Only begin work after the owner explicitly approves with "start karo" or similar clear go-ahead.

## Autonomy boundary

This rule applies to **new, unapproved proposals/research**. It does **not** replace the existing autonomous execution authorization for already-approved or in-progress work (routine commands, deploys, fixes, and the active 20-day plan).
