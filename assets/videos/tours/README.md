## Script Reference

Voiceover scripts in English and Hindi are already included on `tour_videos.php`. Use them to record the audio for each video.

## Uploading

- Keep each MP4 under 50 MB for fast page load.
- 1080p (1920x1080) or 720p (1280x720) is ideal.
- Do not commit MP4 files to Git; they are ignored in `.gitignore`.
